# _references — 참고자료 보관소 (커밋되지 않음)

글을 쓰면서 참고한 논문·교재·데이터시트·측정 데이터를 여기에 둔다.
**이 폴더의 내용물은 git 에 올라가지 않는다.** 이 README 만 추적된다.

## 왜 커밋하지 않는가

- 논문 PDF 는 보통 한 편에 수 MB 다. 몇십 편만 쌓여도 클론이 무거워지고,
  한번 커밋하면 파일을 지워도 히스토리에 남아 되돌리기 번거롭다.
- 상당수는 배포 라이선스가 없어 공개 저장소에 두면 안 되는 자료다.

## Jekyll 이 이걸 게시하지 않는 이유

폴더 이름이 `_` 로 시작하면 Jekyll 이 빌드 대상에서 제외한다.
추가로 `_config.yml` 의 `exclude` 에도 넣어 두 겹으로 막아 두었다.
과거에 `CLAUDE.md` 가 제외되지 않아 사이트에 그대로 게시된 적이 있어서,
여기서는 확실히 해 둔다.

## 정리 방식

포스트 slug 로 폴더를 나눈다. `assets/img/posts/<slug>/` 와 같은 규칙이다.

```
_references/
  <slug>/                     # 해당 포스트가 참고한 자료
    fujiwara-ch2.pdf
    measured-spectrum.csv
    notes.md                  # 읽으면서 남긴 메모
  _thesis/                    # 특정 글에 매이지 않는 상시 참고자료
    서울대학교_김영준_박사_학위_논문_compressed.pdf
```

## 백업

이 폴더는 git 이 지켜주지 않는다. 레포 자체가 Dropbox 안에 있어 동기화는
되지만, 중요한 자료라면 원본 출처(DOI, 링크)를 `notes.md` 에 같이 적어 두는 편이
안전하다. 포스트의 "참고자료" 절에도 링크가 남으므로 이중으로 보존된다.
