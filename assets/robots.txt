# ─────────────────────────────────────────────────────────────
# RSL (Really Simple Licensing) — 이 사이트 콘텐츠의 이용 조건
# 검색 색인은 무료, AI 학습·추론 사용은 출처 표기 + 유료입니다.
# 전문(기계 판독용): /license.xml
#
# RSL 의 `License:` 지시어를 여기 두면 Google Search Console 이
# "식별할 수 없는 구문"으로 심각한 오류를 띄운다. RFC 9309 상 모르는 줄은
# 무시하게 되어 있지만, robots.txt 는 크롤링 전체를 좌우하는 파일이라
# 경고를 안고 갈 이유가 없다. RSL 이 공식 지원하는 다른 방법인 HTML
# <link type="application/rsl+xml"> 로 옮겼다 (_includes/metadata-hook.html).
# ─────────────────────────────────────────────────────────────
